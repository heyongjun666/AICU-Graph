# AICU-Graph
AICU 是一个面向复杂任务的动态多智能体协作平台，能够根据任务目标实时构建和调整 AI Agent 组织，让不同能力的 Agent 按需组成团队，共同完成复杂、长期且不断变化的任务。  与传统 Multi-Agent 框架依赖预定义角色、固定工作流或固定 Agent 拓扑不同，AICU 不预先规定一套完整的协作流程，而是根据当前任务动态组织所需的 Agent，并随着任务进展不断调整协作关系和工作分工。不同 Agent 可以独立执行专业工作，并在需要时进行协作，共同推动任务向最终目标发展。  AICU 的核心目标，是让 AI 从“一个 Agent 执行一个任务”进一步发展为能够实时组建、管理和调整 AI 团队来完成复杂任务的系统。
