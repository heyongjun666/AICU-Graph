## 1. 系统简介

本平台是一个**支持 Markdown 的在线博客系统**，采用 Python 编写，使用 **CSV 文件**存储数据（不引入数据库系统）。系统包含以下核心能力：

| 功能域 | 说明 |
| --- | --- |
| 文章管理 | 文章的发布、编辑、列表、详情、归档与删除 |
| 标签系统 | 标签的创建、重命名、删除，以及按标签筛选文章 |
| 阅读统计 | 阅读次数记录、站点统计总览、阅读趋势、热门文章排行 |
| 其他 | Markdown 实时预览、图片上传、RSS 订阅、账号认证 |

> **术语说明**
> - **文章（Article）**：博客的基本内容单元，以 Markdown 文本编写。
> - **标签（Tag）**：用于给文章分类的关键字，一篇文章可挂多个标签。
> - **阅读量（Read Count）**：文章被阅读的次数，由系统在阅读行为发生时记录。
> - **草稿（Draft）**：尚未公开发布的文章状态；草稿不会出现在公开的文章列表中。
> - **发布（Publish）**：将文章状态置为「已发布」，使其对读者可见。

## 2. 启动与访问

### 2.1 环境要求

- Python 3.10+（后端运行时）
- Node.js 18+（前端构建，可选）

### 2.2 启动后端

在项目根目录（`backend/` 的上级目录）执行：

```bash
# 1. 安装后端依赖
pip install -r backend/requirements.txt

# 2. 启动 Flask 服务（默认端口 8000）
python -m backend.app
```

启动成功后，后端服务监听 `0.0.0.0:8000`，所有 API 以 `/api/v1` 为前缀，例如：

- 健康检查：`http://localhost:8000/api/v1/health`
- 文章接口：`http://localhost:8000/api/v1/articles`

### 2.3 访问 Web 页面

在浏览器中打开：

```
http://localhost:8000
```

系统会自动托管前端静态页面（`frontend/` 目录）。若通过前端开发服务器运行，请将页面访问地址指向对应端口。

### 2.4 数据文件说明

数据以 CSV 文件形式保存在 `backend/data/` 目录下（可用环境变量 `BLOG_DATA_DIR` 覆盖），主要包括：

| 文件 | 内容 |
| --- | --- |
| `articles.csv` | 文章主表（标题、正文、标签、创建/更新时间等） |
| `tags.csv` | 标签表 |
| `read_stats.csv` | 阅读统计表（文章阅读次数、最后阅读时间） |

> 上传的图片默认保存在 `backend/uploads/` 目录（可用环境变量 `BLOG_UPLOAD_DIR` 覆盖）。

## 4. 文章列表与浏览

文章列表页（首页）是读者浏览文章的入口，页面从上到下依次为：

```
┌─────────────────────────────────────────────┐
│ 文章列表                                     │
│ [搜索文章标题...        ]                    │
│ ┌──────────┐ ┌────────────────────────────┐ │
│ │ 标签筛选  │ │  [文章卡片] [文章卡片]      │ │
│ │ 全部文章 N│ │  [文章卡片] [文章卡片]      │ │
│ │ 标签A   n│ │  [文章卡片] [文章卡片]      │ │
│ │ 标签B   m│ │                             │ │
│ └──────────┘ │      [上一页] 1 2 3 [下一页] │ │
│              └────────────────────────────┘ │
└─────────────────────────────────────────────┘
```

### 4.1 浏览文章卡片

列表以**卡片**形式展示文章，每张卡片包含：

- **标题**：最多显示两行。
- **摘要**：正文开头内容的截取，最多两行。
- **日期**：优先显示发布时间，未发布时显示创建时间。
- **标签**：以彩色小徽章（chip）展示。
- **草稿标识**：若文章处于草稿状态，卡片右上角显示「草稿」黄色徽章。

点击任意卡片即可进入对应的文章详情页。

### 4.2 搜索文章

- 在顶部搜索框输入关键词后按 **Enter** 键，即按标题搜索文章。
- 输入内容后搜索框右侧出现「清除」按钮（×），点击可清空关键词并恢复完整列表。
- 搜索会重置到第一页。

### 4.3 按标签筛选

在左侧「标签筛选」侧栏中：

- **全部文章**：显示全部已发布文章，并给出总数。
- **每个标签**：显示标签名及其文章数，点击后列表只展示带有该标签的文章。

> 若列表页使用顶部的分类标签条（标签页签）而非侧栏，则点击「全部」或某个标签页签同样可以筛选。筛选会重置到第一页。

### 4.4 分页浏览

- 列表每页显示 **20** 篇文章。
- 底部提供分页控件：上一页 / 下一页、页码按钮；页码较多时以 `...` 省略。
- 仅当页数大于 1 时显示分页控件。

### 4.5 列表状态

| 状态 | 表现 | 处理方式 |
| --- | --- | --- |
| 加载中 | 显示骨架屏 | 等待加载完成 |
| 加载失败 | 显示「加载失败」与「重试」按钮 | 点击「重试」重新加载 |
| 空数据 | 显示「还没有文章 · 快去写第一篇吧」 | 点击导航栏「写文章」开始写作 |

## 5. 查看文章详情

点击文章卡片进入详情页，页面布局如下：

```
┌──────────────────────────────────────────────┐
│ ‹ 返回列表                                    │
│                                              │
│ 文章标题                                      │
│ 2026-08-01 14:30 · 字数 1,024   [草稿]        │
│ [标签A] [标签B]                               │
│ ────────────────────────────────────────────  │
│                                              │
│  (Markdown 渲染后的正文内容)                   │
│                                              │
└──────────────────────────────────────────────┘
```

### 5.1 页面元素

| 元素 | 说明 |
| --- | --- |
| `返回列表` | 回到文章列表页 |
| 标题 | 以一级标题展示 |
| 元信息 | 日期（优先发布时间）、字数、草稿状态徽章 |
| 标签 | 文章所属标签，以徽章展示 |
| 正文 | Markdown 渲染后的完整内容 |

### 5.2 Markdown 渲染效果

正文按 Markdown 语法渲染，支持：

- 标题（H1~H6）、段落、加粗、斜体、删除线
- 无序/有序列表、引用、水平分割线
- 代码块（自动语法高亮）、行内代码
- 链接、图片
- 表格

正文渲染经过 HTML 净化处理，标题自动生成锚点（heading anchor），便于定位。

> 草稿文章同样可以打开详情页查看，元信息处显示「草稿」徽章。

## 6. 写文章与编辑文章

点击导航栏「写文章」进入**新建文章页**；在编辑场景下从对应入口进入**编辑文章页**。两个页面共用同一编辑器界面，区别仅在于编辑页会先加载已有文章内容。

```
┌──────────────────────────────────────────────────┐
│ 新建文章                 [取消] [存为草稿] [发布]   │
│ ┌──────────────────────────────────────────────┐ │
│ │ 输入文章标题                                  │ │
│ └──────────────────────────────────────────────┘ │
│ 标签                                            │
│ [标签A] [标签B] [标签C] ...                     │
│                                                 │
│ 内容 (Markdown)              预览               │
│ ┌───────────────────────┐ ┌───────────────────┐ │
│ │ 工具栏: ↶ ↷ | B I |   │ │   (实时渲染结果)    │ │
│ │ H1 H2 H3 | •≡ 1. ❝  │ │                   │ │
│ │ </> 🔗 🖼 ― | 🌙      │ │  字数: ~1,024      │ │
│ │                       │ │                   │ │
│ │ (编辑区)               │ │                   │ │
│ └───────────────────────┘ └───────────────────┘ │
└──────────────────────────────────────────────────┘
```

### 6.1 填写标题

- 在标题输入框（提示「输入文章标题」）中填写标题。
- 标题**必填**，为空时点击保存会提示「请输入文章标题」。
- 标题长度限制为 1–200 个字符。

### 6.2 选择标签

- 「标签」区域展示当前所有可用标签。
- 点击标签徽章可**选中 / 取消选中**；选中的标签以蓝色高亮显示。
- 保存文章时，所选标签会一并写入文章。

### 6.3 使用 Markdown 编辑器

「内容 (Markdown)」区域提供 Markdown 编辑器，顶部工具栏从左到右为：

| 按钮 | 作用 | 快捷键 |
| --- | --- | --- |
| ↶ | 撤销 | Ctrl+Z |
| ↷ | 重做 | Ctrl+Shift+Z |
| **B** | 加粗 | Ctrl+B |
| *I* | 斜体 | Ctrl+I |
| H1 / H2 / H3 | 插入 1~3 级标题 | — |
| •≡ | 无序列表 | — |
| 1. | 有序列表 | — |
| ❝ | 引用 | — |
| `</>` | 代码块 | — |
| 🔗 | 插入链接 | Ctrl+K |
| 🖼 | 插入图片 | Ctrl+Shift+K |
| ― | 水平分割线 | — |
| 🌙 / ☀ | 切换编辑器亮/暗主题 | — |

> 说明：编辑器最大内容长度为 100,000 字符，超出部分将被拦截。

### 6.4 实时预览

- 「预览」面板随编辑内容**实时渲染** Markdown，与正文展示效果一致。
- 预览区底部显示当前内容字数（如 `字数: ~1,024`）。

### 6.5 保存操作

页面右上角提供三个操作按钮：

| 按钮 | 行为 |
| --- | --- |
| `取消` | 放弃编辑，返回文章列表 |
| `存为草稿` | 以草稿状态保存（不公开） |
| `发布` | 以已发布状态保存，对读者可见 |

- 保存成功后自动返回文章列表页。
- 保存失败时，页面顶部显示红色错误提示条。

> **新文章默认状态**：新建的文章默认以草稿保存；通过「发布」按钮保存后即为已发布文章。

### 6.6 编辑已有文章

- 编辑页加载时会显示骨架屏，随后自动填充标题、标签与正文。
- 修改后同样可选择「存为草稿」或「发布」。
- 若加载失败，页面显示「加载失败 · 无法加载文章数据」并提供「返回列表」按钮。

## 7. 发布与文章状态

### 7.1 文章状态

文章具有以下状态：

| 状态 | 说明 | 是否出现在公开列表 |
| --- | --- | --- |
| 草稿（draft） | 未公开发布 | 否 |
| 已发布（published） | 对读者可见 | 是 |
| 已归档（archived） | 已从列表隐藏归档 | 否 |

### 7.2 发布文章

两种方式均可将文章设为已发布：

1. 在编辑器中点击「**发布**」按钮直接保存为已发布状态。
2. 对已保存的草稿，调用发布接口将其状态置为「已发布」。

发布后文章即出现在公开列表中，并可通过 RSS 订阅获取。

### 7.3 归档文章

对已发布文章可执行**归档**操作，归档后文章不再出现在公开列表。

> 归档为内容管理动作，一般由站点维护人员在管理入口执行。

### 7.4 删除文章

- 删除后文章即被移除，详情页与列表中不再可见。
- 删除操作同时清理该文章的阅读统计数据。

### 7.5 权限说明

发布、归档、编辑、删除均属于**写操作**，需要登录身份（详见 [第 10 章](#10-用户账号与权限)）。

## 8. 标签系统

「标签」页用于管理全部标签，页面布局如下：

```
┌──────────────────────────────────────────┐
│ 标签管理                          [新建标签] │
│ ┌──────────────────────────────────────┐  │
│ │ 标签名              N 篇文章    [✎] [🗑] │  │
│ │ 标签名              M 篇文章    [✎] [🗑] │  │
│ │ ...                                   │  │
│ └──────────────────────────────────────┘  │
└──────────────────────────────────────────┘
```

### 8.1 新建标签

1. 点击右上角「**新建标签**」按钮。
2. 在弹出的输入框中输入标签名称，点击「**确认**」（或按 **Enter**）创建。
3. 按 **Escape** 或点击「**取消**」放弃创建。

> 标签名称长度限制为 1–50 个字符，且不可与已有标签重名。

### 8.2 重命名标签

1. 将鼠标悬停在某标签行上，点击「**重命名**」图标（✎）。
2. 标签名变为可编辑输入框，修改后点击「**确认**」（或按 **Enter**）保存。
3. 按 **Escape** 或点击「**取消**」放弃修改。

### 8.3 删除标签

1. 将鼠标悬停在某标签行上，点击「**删除**」图标（🗑）。
2. 弹出确认框：「确定删除标签 \"xxx\" 吗？」。
3. 点击「**确定**」执行删除；点击「**取消**」放弃。

> 删除标签后，该标签会从所有关联的文章中移除，但**文章本身不会删除**。

### 8.4 标签合并

系统还提供标签**合并**能力：可将「源标签」下的全部文章转移到「目标标签」下，随后源标签被移除。适用于标签重名/冗余的整理场景。

### 8.5 通过标签跳转

- 点击任意标签行，可跳转到文章列表并按该标签筛选。
- 标签管理页的「新建 / 重命名 / 删除 / 合并」均属**写操作**，需要登录身份。

## 9. 阅读统计

「统计」页集中展示站点与文章的阅读数据，页面布局如下：

```
┌──────────────────────────────────────────────────────┐
│ 阅读统计                                              │
│ [总文章数] [总阅读量] [总读者数] [平均阅读时长]          │
│                                                      │
│ 阅读趋势                   [每日] [每周] [每月]        │
│   (SVG 柱状图)                                        │
│                                                      │
│ 热门文章 TOP 10             文章统计详情               │
│ ┌─────────────────────┐   ┌──────────────────────┐   │
│ │ 排名 标题 阅读量 ...  │   │ 总阅读量  总阅读时长   │   │
│ │ ①   文章A  1.2K      │   │ 平均阅读时长 完成率    │   │
│ │ ②   文章B  800       │   │ 阅读完成率  [██████]  │   │
│ └─────────────────────┘   └──────────────────────┘   │
└──────────────────────────────────────────────────────┘
```

### 9.1 阅读量如何产生

- 读者**阅读文章**时，系统通过阅读记录接口为该文章累计阅读次数。
- 文章详情接口会返回该文章的 `read_count`（阅读量）。
- 站点级统计接口汇总文章总数、标签总数、阅读总量、热门文章排行及按标签的阅读分布。

### 9.2 摘要卡片

顶部为四张汇总卡片：

| 卡片 | 指标 |
| --- | --- |
| 总文章数 | 站点文章总量 |
| 总阅读量 | 全部文章累计阅读次数 |
| 总读者数 | 去重读者数量 |
| 平均阅读时长 | 单次阅读的平均时长 |

数值超过 1000 时以 `K`/`M` 缩写显示（例如 `3.2K`）。

### 9.3 阅读趋势

- 「阅读趋势」以柱状图展示阅读量的时间变化。
- 顶部提供「**每日 / 每周 / 每月**」切换按钮，切换后图表数据相应更新。
- 无数据时图表区显示「暂无数据」。

### 9.4 热门文章 TOP 10

「热门文章 TOP 10」表格按阅读量从高到低列出文章，包含列：

| 列 | 说明 |
| --- | --- |
| 排名 | 前三名分别以金/灰/橙圆形徽章标识 |
| 标题 | 文章标题 |
| 阅读量 | 阅读次数 |
| 阅读时长 | 累计阅读时长（如 `3m 5s`） |
| 完成率 | 阅读完成比例，≥70% 绿色、≥40% 黄色、否则红色 |

- 点击任意一行，右侧加载该文章的**统计详情**。

### 9.5 单篇文章统计

右侧「文章统计详情」面板展示选中文章的指标：

| 指标 | 说明 |
| --- | --- |
| 总阅读量 | 该文章累计阅读次数 |
| 总阅读时长 | 累计阅读时长 |
| 平均阅读时长 | 平均单次阅读时长 |
| 完成率 | 阅读完成比例，并配有进度条展示 |

- 点击左上角「返回」按钮可关闭详情面板。

### 9.6 数据加载状态

- 首次加载显示骨架屏。
- 加载失败显示「加载失败 · 请检查网络连接后重试」及「重试」按钮。
- 切换趋势周期时，已有数据保持可见，仅更新对应周期数据。

| 接口/操作 | 说明 |

- 文章列表、搜索、按标签筛选

## 11. 其他功能

### 11.1 图片上传

- 系统提供图片上传能力，支持格式：`png / jpg / jpeg / gif / webp / svg`。
- 上传成功后返回图片 URL，可用于文章正文中的图片引用。
- 上传接口需登录身份。

### 11.2 Markdown 预览

- 编辑器中提供实时预览（见 [6.4 实时预览](#64-实时预览)）。
- 系统亦提供独立的 Markdown 预览接口：传入 Markdown 文本即返回渲染后的 HTML。

- 已发布的文章可通过 RSS 订阅获取，访问地址：

```
http://localhost:8000/api/v1/rss.xml
```

- RSS 输出为 RSS 2.0 格式（`application/rss+xml`），包含最近 20 篇已发布文章的标题、链接、摘要与发布日期。

- 服务健康状态可通过以下地址查看：

| 地址 | 说明 |
| --- | --- |
| `/api/v1/health` | 服务健康状态（`status: ok`） |
| `/api/v1/liveness` | 存活检查（`status: alive`） |
| `/api/v1/readiness` | 就绪检查（`status: ready`） |

## 12. 常见问题

**Q1：为什么我在列表页看不到刚写的文章？**

新建文章默认是**草稿**状态，不会出现在公开列表。请在编辑页点击「**发布**」将其发布，或通过写操作将其置为已发布状态。

**Q2：发布、编辑、删除文章时提示需要认证？**

这些属于写操作，需要先登录并携带访问令牌（`Authorization: Bearer <token>`）再执行。

**Q3：删除标签会影响文章吗？**

删除标签只会从所有关联文章中移除该标签，文章本身不会受影响。

**Q4：阅读量什么时候增加？**

每次文章被阅读时，系统通过阅读记录接口为该文章累计一次阅读。相关阅读数据可在「统计」页查看。

**Q5：如何订阅博客更新？**

使用 RSS 阅读器订阅 `/api/v1/rss.xml` 即可获取已发布文章的更新。

**Q6：数据存放在哪里？**

所有业务数据以 CSV 文件保存在 `backend/data/` 目录下；上传的图片保存在 `backend/uploads/` 目录下。
