# 数学证明审查纪律

对一份数学证明做对抗性审查，目标是找出漏洞、构造反例，并给出「成立 / 有缺陷 / 不成立」的判定。默认怀疑每一个断言，只接受有充分依据的推导。

## 审查顺序

1. **对齐命题**：先明确要证明的命题与全部假设。判定一条证明的第一步，是核对它证明的结论是否与给定命题一致——偷换结论、弱化结论、遗漏退化情形都属于致命缺陷。
2. **检查假设使用**：每个假设是否都被用上、是否被正确使用、是否混入了未声明的假设。
3. **逐行核验**：对每一步检查推导是否合法、依据是否充分、是否存在跳步。
4. **构造反例**：对可疑断言尝试构造具体反例，用真实对象证伪，不要停留在「感觉不对」。
5. **判定成立性**：汇总为「成立 / 有缺陷 / 不成立」之一，每条结论附定位与理由。

## 常见漏洞清单

- **跳步**：从 A 直接到 C，中间需要的 B 未给出。
- **未声明假设**：使用了证明中未列出的前提。
- **偷换结论**：证明的是比目标命题弱或不同的结论。
- **循环论证**：用待证结论（或等价命题）来证明待证结论。
- **退化情形遗漏**：`n=0`、边界点、空集、退化矩阵等特殊情形未处理。
- **量化词混淆**：`∀` 与 `∃` 的次序、统一收敛 vs 逐点收敛等。
- **不成立的反向断言**：从「P 蕴含 Q」推出「Q 蕴含 P」。
- **泛化过度**：把小范围结论推广到不满足条件的更大范围。
- **记号歧义**：同一记号在不同步骤含义不同。
- **数值当严格**：把浮点近似或有限样本当作严格等式/普遍规律。

## 反例构造策略

- **退化情形**：先试 0、1、空集、单位元、平凡群/平凡环等。
- **极值/边界**：逼近定义域边界或不等式取等处的对象。
- **维度升级/降级**：一维结论试二维，低阶试高阶。
- **离散扰动**：对连续结论试离散对象，反之亦然。
- **特殊结构**：对称、稀疏、对角、常值等容易被忽略的结构。

## 判定标准

- **成立**：命题一致、假设正确使用、每步有据、所有情形覆盖、无未声明前提。
- **有缺陷**：存在跳步、未声明假设或遗漏情形，但缺陷可能可修补；列出缺陷并定位。
- **不成立**：找到了有效反例，或发现了无法修补的逻辑错误。

## 输出约定

- 每条发现写「步骤定位 → 缺陷类型 → 影响 → 建议」。
- 只报告缺陷与建议，不直接改写证明（修补由证明者完成）。
- 反例必须是可核验的具体对象，附核验过程。
